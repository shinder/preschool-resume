# 成本評估

日期：2026-08-08（原估 2026-08-07，含競品查核後修正）
來源：整合自 `~/practices/app2/docs/04_五大題目成本評估.md` 題目 5 相關內容。

## 一、評估前提

- 以「一人開發者＋AI 協作開發」為基準；人力成本以「人月」計，不折算薪資。
- 主機費用以獨立開發者常見組合估算：VPS（如 Hetzner、Linode 約 US$10–40/月）或 Cloudflare Workers/Pages＋R2/D1。
- 匯率概算：US$1 ≈ NT$31。

## 二、成本總覽

| 項目 | 估算 |
|---|---|
| 技術複雜度 | 低（五題中最低） |
| MVP 時間 | 1 個月內（托嬰＋幼兒園＋推播） |
| 完整版時間 | 2–3 個月（含補習班／課照中心） |
| 一次性成本 | 近乎 0 |
| 每月固定成本 | NT$500–1,500 |
| 持續維運負擔 | 低中（托嬰／幼兒園有全國集中源；補習班仍分散） |

## 三、細項

- **技術成本**：低。
  - 托嬰中心與幼兒園各一支爬蟲即可（全國集中源）；縣市分散、需逐一爬取的只剩補習班與課照中心。
  - 關鍵工程：裁罰公告的持續備份＋異動偵測（diff 邏輯）＋推播（Web Push 或 LINE）。
- **人力成本**：托嬰＋幼兒園約 0.5–1 人月可上線；補習班／課照擴充另計 1–1.5 人月（此部分才有縣市爬蟲的維運負擔）。
- **主機與外部費用**：五題中最低。
  - 資料量小（全台機構數萬筆等級），Cloudflare Workers＋D1 免費額度可能就夠，上限 NT$500–1,500/月。
  - 幾乎不需要 LLM（裁罰事由可原文呈現，摘要為選配）。

## 四、前端形式

**Web＋LINE 推播起步，是五題中唯一值得後續上 App 的題目**：

- 家長從懷孕到孩子上小學有數年的持續追蹤需求，高頻回訪＋推播是核心價值，符合 app 的成立條件。
- 但「機構頁吃 SEO」的獲客假設已作廢——免費競品已卡位查詢與 SEO 流量。本題不做查詢入口，直接以 LINE 推播訂閱驗證留存。
- 等付費訂閱者達千人等級再投入 app（追加約 2–3 人月＋雙平台維護）。一人團隊不該在現金流出現前背雙平台維護成本。

推播需求先用替代方案擋：LINE 官方帳號／Messaging API 與 Web Push 可以滿足八成推播場景，成本遠低於 app。

## 五、風險備註

免費、高信譽的公益競品已存在，C 端查詢收不到錢；價值只能建立在競品沒做的深度層（追蹤推播、負責人歸戶、跨類別整合、B 端 API）。收入天花板比原估更低——成本雖是五題最低，優先度也是五題之末。
