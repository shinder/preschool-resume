## 二、真正的護城河：官方裁罰資料會下架

依政府資料開放平臺的報導（data.gov.tw/news/27550）：

- 全國教保資訊網的裁罰紀錄公告**依處分輕重 3 個月至 6 年到期即下架**。
- 台灣幼兒園地圖（kiang）因持續備份，歷史紀錄仍可查。

這代表：**歷史裁罰資料庫是時間累積型資產，後進者無法回溯補抓**——這比爬蟲苦工更硬的門檻。但此累積優勢目前在 kiang 手上（已備份多年），不在新進者手上。若要做這題，「從今天開始備份」是第一件事，且越晚開始差距越大。

## 三、關鍵工程

1. **裁罰公告的持續備份**：對抗官方下架，是本專案的資產核心。
2. **異動偵測**：diff 邏輯，偵測新裁罰、狀態變更、機構異動。
3. **負責人歸戶**：把機構歸戶到負責人實體，偵測「換牌重開」（被裁罰後換名字重新立案）。這是競品全部沒做的部分，也是與建商履歷共用的歸戶技術。
4. **推播**：Web Push 或 LINE Messaging API。

幾乎不需要 LLM——裁罰事由可原文呈現，摘要為選配。

## 四、護城河判斷的方法論教訓

同一輪評估在五題中，「把公開資料的取得與歸戶當門檻」錯了四次——免費公益專案（g0v、kiang、LawPlayer）的覆蓋一再超出預期。可靠的護城河來源是結構性的：

- **誰因利益衝突不能做**（如 591 不能做建商負評）。
- **什麼資料因官方下架而無法回溯補抓**（本題的裁罰公告備份即屬此類）。
- **什麼品質門檻錯一次就掉客戶**（法律／標案摘要正確率）。

本題唯一符合的是第二類，且需要時間累積才成立。

## 五、法遵與其他注意事項

- 所有引用開放資料的產品都要標示來源（政府資料開放授權條款第 1 版）。
- 若需要地圖介面：內政部國土測繪中心「國土測繪圖資服務雲」的台灣通用電子地圖 WMTS 服務**免申請、免費介接**（maps.nlsc.gov.tw/S_Maps/wmts），需標示資料來源；kiang 的地圖系列即以此取代 Google Maps 費用。注意：部分向量圖資 WFS 與特定 API 需申請，且主要開放政府與學術單位；商業大流量使用前先確認介接服務說明（maps.nlsc.gov.tw/S09SOA）。
